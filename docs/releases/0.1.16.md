# RaTeX-CMP 0.1.16

## English

RaTeX-CMP 0.1.16 upgrades the bundled RaTeX core and Web JS/Wasm runtime to
`0.1.16`, correcting equation labels and multi-digit automatic equation numbers.

### Fixed

- `\tag{...}` and `\tag*{...}` render labels as upright text, matching KaTeX.
  Labels can mix text with math enclosed in `$...$`.
- Unbraced label macros expand completely in text mode, and spaces after
  `\tag*` are handled correctly.
- Automatic equation numbers render every digit, including `(10)`, `(11)`,
  and subsequent numbers.

### Compatibility

- Math inside a label now requires `$...$`: replace `\tag{x^2}` with
  `\tag{$x^2$}`. Nested `\tag` commands inside a label are rejected.
- Existing CMP parsing/rendering APIs and the DisplayList protocol remain unchanged.
- Chemistry commands such as `\ce` and `\pu` remain available.
- JVM Desktop applications should use matching `0.1.16` native runtime artifacts.

## 中文

RaTeX-CMP 0.1.16 将内置 RaTeX 核心和 Web JS/Wasm 运行时统一升级至 `0.1.16`，
修复公式标签和多位自动公式编号的显示。

### 修复

- `\tag{...}` 和 `\tag*{...}` 的标签以正体文本显示，与 KaTeX 一致；
  标签中可混合文本与使用 `$...$` 包裹的数学内容。
- 不带花括号的标签宏在文本模式下完整展开，并正确处理 `\tag*` 后的空格。
- 自动公式编号完整显示每一位数字，包括 `(10)`、`(11)` 及后续编号。

### 兼容性

- 标签内的数学内容现在需要使用 `$...$`：请将 `\tag{x^2}` 改为
  `\tag{$x^2$}`。标签内部不再允许嵌套 `\tag`。
- 现有 CMP 解析、绘制 API 和 DisplayList 协议保持不变。
- `\ce`、`\pu` 等化学公式命令仍然可用。
- JVM Desktop 应用应使用同版本 `0.1.16` 的 native runtime 依赖。

## Upgrade / 升级方式

```kotlin
implementation("io.github.darriousliu:ratex:0.1.16")
```

For JVM Desktop, also add the artifact matching the target platform. For example,
on macOS arm64 / JVM Desktop 还需添加与目标平台对应的原生库，例如 macOS arm64：

```kotlin
runtimeOnly("io.github.darriousliu:ratex-native-darwin-aarch64:0.1.16")
```
