# RaTeX-CMP 0.1.15

## English

RaTeX-CMP 0.1.15 upgrades the bundled RaTeX core and Web JS/Wasm runtime to
`0.1.15`, adds a macOS arm64 Kotlin/Native target, and improves formula layout,
input validation, and native build verification.

### Added / improved

- Support for `\slashed` and `\centernot`, with examples for Dirac notation,
  relation negation, labeled arrows, and inline scripts.
- A `macosArm64` Kotlin/Native target and a standalone macOS sample, alongside
  the existing JVM Desktop targets.
- Formula color inheritance for boxes, fraction rules, explicit rules, and paths.
- Regression coverage for macro expansion and layout resource limits, overflowing
  `\char` values, and successful parsing after errors.

### Build and compatibility

- Keep existing CMP parsing/rendering APIs and the DisplayList protocol unchanged.
- Rebuild iOS Rust libraries with `panic_abort` and verify unwind relocations
  before packaging to address native linking failures.
- Verify Android 64-bit ELF LOAD/GNU_RELRO alignment for 16 KB pages, including
  the libraries inside the published AAR.
- Align all Android modules to `compileSdk = 37`.
- Build with Kotlin `2.4.20`, Compose Multiplatform `1.12.2`, AGP `9.4.1`, and
  Android Compose BOM `2026.09.00`.
- JVM Desktop applications should use matching `0.1.15` native runtime artifacts.

## 中文

RaTeX-CMP 0.1.15 将内置 RaTeX 核心和 Web JS/Wasm 运行时统一升级至 `0.1.15`，
增加 macOS arm64 Kotlin/Native 目标，改进公式布局、输入校验和原生构建验证。

### 新增 / 改进

- 支持 `\slashed` 和 `\centernot`，新增 Dirac 记号、关系否定、带标签箭头和行内上下标示例。
- 增加 `macosArm64` Kotlin/Native 目标及独立 macOS 示例，保留现有 JVM Desktop 目标。
- 改进方框、分数线、显式横线和路径对公式颜色的继承。
- 增加宏展开与布局资源限制、`\char` 数值溢出及错误后恢复的回归覆盖。

### 构建与兼容性

- 现有 CMP 解析、绘制 API 和 DisplayList 协议保持不变。
- iOS Rust 库使用 `panic_abort` 重编标准库，并在打包前检查 unwind 重定位，修复原生链接问题。
- 验证 Android 64 位 ELF LOAD/GNU_RELRO 的 16 KB 页对齐，发布 AAR 中的库也执行相同检查。
- 所有 Android 模块统一使用 `compileSdk = 37`。
- 构建工具更新至 Kotlin `2.4.20`、Compose Multiplatform `1.12.2`、AGP `9.4.1` 和
  Android Compose BOM `2026.09.00`。
- JVM Desktop 应用应使用同版本 `0.1.15` 的 native runtime 依赖。

## Upgrade / 升级方式

```kotlin
implementation("io.github.darriousliu:ratex:0.1.15")
```

For JVM Desktop, also add the artifact matching the target platform. For example,
on macOS arm64 / JVM Desktop 还需添加与目标平台对应的原生库，例如 macOS arm64：

```kotlin
runtimeOnly("io.github.darriousliu:ratex-native-darwin-aarch64:0.1.15")
```
